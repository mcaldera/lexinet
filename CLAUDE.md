# Plexus (repo: lexinet; called Sprawl until Sep 2026)

Vocabulary trainer as a mind-map game, for Italian and (since Oct 2026) Spanish (Spain) and German, all from English. Words are nodes in a graph; answering a word correctly starts learning it and reveals its neighbours; memory (FSRS) decides when a word weakens and **signal** (what your words pass to each other along links, more the better you know them; `supply` in the code) decides what that costs. The author (Michael) is user #1 and iterates fast with feature requests.

**Names on screen vs in code.** Until Sep 2026 the game spoke of conquest (territory, supply, capital, raids). The author liked the game but not the war words for a vocabulary trainer, so the UI moved to a mind theme and the app became **Plexus**; the code, DB and storage keys (`sprawl.*`) kept the old names so saves carry over. Write UI text with the left column, code with the right:

| on screen | in code |
|---|---|
| learn / learned, learning 1/3 | conquer / conquered, claim / claimed |
| new word, "?" | frontier |
| faint (out of reach) | ghost |
| signal, connected | supply, supplied |
| disconnected | cut off (`cut`) |
| slipped (missed or forgotten) | broken (`broken`, `missedAt`) |
| fades (back to "?") | falls (siege) |
| recover | reclaim / win back (`fallen`) |
| core word | capital (`seed`) |
| anchor (gold rays) | stronghold (`towers`) |
| N words depend on it | hanging on it, chokepoint |
| focus | expedition |
| pop quiz | raid |
| connect a word | plant (`user_edges`) |
| sparks | coins |
| English cousin | hint (`hints`, `cognate`) |
| a root clicks | a root opens (`unlocked_roots`) |
| topic | category, region |
| the word (Italian, Spanish, …) / its English | `it` / `en` (fields, `it-en`/`en-it` card directions, `checkAnswer(…, 'it')`) |

`docs/PROPOSAL.md` is the original v0.1 plan. The project has since gone well beyond it at the author's request (tiers, verbs, supply game, claims, etymology, multiple word lists). Treat this file as the current source of truth; the proposal's "out of scope" list no longer binds. The supply game replaced an earlier influence game (control, hostile words, danger, landmarks, reach push) in Sep 2026: the author found three per-word numbers too confusing, but wants the network central (not plain flashcards). Later in Sep 2026 organic supply (every held word a source, by memory strength) replaced supply nodes earned every 12 words and placed by hand: the author found placing them too fiddly.

## Stack

- React 19 + TypeScript + Vite 5 + Tailwind 3; graph: `react-force-graph-2d` (canvas); scheduling: `ts-fsrs` 4.x; tests: Vitest 2
- Fonts bundled offline via `@fontsource` (imported in `main.tsx`, families in `tailwind.config.js` and `visuals.ts`): Inter (UI, word names on the map), Newsreader (`font-serif`: Italian headwords and example sentences in the cards, like a dictionary entry; Cormorant set Italian graves steep and off to the side, "così"), Cinzel (Roman capitals: region names, big titles), Cormorant Garamond italic (Latin roots, English cousins). The canvas redraws once they load.
- No emoji in the UI (the author found them cheap-looking, "too much like AI"): `views/Icon.tsx` has line icons (24 px grid, `currentColor`, 1em) and `Sparks` (a price or balance). Typographic marks (★ tenses, ◎ verb points, ↺, ≈) are fine.
- Tauri 2 shell in `src-tauri/` (thin, untested: this dev box has no Rust toolchain or webkit2gtk). Day-to-day the app runs in the browser.
- Persistence: SQLite. Tauri → `@tauri-apps/plugin-sql`; browser → `sql.js`, snapshotted as bytes to IndexedDB (`src/db/store.ts`: database `sprawl`, store `databases`, key `sprawl.db`, or `sprawl-<graph>.db`; further runs `sprawl-<graph>~<run>.db`, see `src/runs.ts`). Until Sep 2026 the snapshots were base64 in localStorage: ~5 M characters per site, 2.2 M per run, so a third database failed to save silently and that run reopened at the start picker. Old snapshots move to IndexedDB on first open; save failures now show as a notice (`onStorageProblem`). localStorage is only the fallback without IndexedDB
- Offline pipeline: Python 3.13 in `pipeline/.venv` (sentence-transformers, networkx, pandas); never bundled

Build it with `pipeline/.venv/bin/python pipeline/build_vocab.py data/vocab/it -o data/graph_oic.json` (~1.5 min; `--check` only validates, `--enrich` first writes missing Wiktionary etymology into the files, review it there). The output keeps the name `graph_oic.json` so existing runs keep their progress (ids = slug of `it`, or the explicit `id` of a renamed word). Edit the YAML, never the JSON. Linking rules: see Pipeline notes.
- **Other languages** are translations of the Italian vocabulary, one folder each: `data/vocab/es/` (Spanish: Spain, `vosotros`). Their files look the same with the word under its language code and `concept` = the Italian word's id (`{es: la mano, en: hand, pos: noun, level: A1, concept: la-mano}`; the code still calls the word `it`). Made with `pipeline/translate_vocab.py --lang es data/vocab/es/translations data/vocab/it data/vocab/es` from one `<category>.txt` per category (kept in `data/vocab/es/translations/`; re-merging overwrites the YAML, which is the truth once edited; a line per Italian word: the word, `word | English` where the senses differ, `-` to leave a concept out, `+ word | English | pos` for an extra one; ser/estar from essere). It copies English, part of speech and level (and the curated Italian root and cousin where the word clearly continues it: casa/casa < casa, noche/notte < nox; `shares_root`), takes plurals from Wiktionary, gives accent-clashing ids a suffix (`si-yes`), and checks every word against Spanish Wiktionary (exists, part of speech, article vs gender, a sense matching the English; plural-only and `-se` entries followed to their base) into `REVIEW.md` next to the files (105 of 2632 flagged, mostly phrases Wiktionary lacks: a review list for someone fluent). `--check FOLDER` re-runs only the check. Build: `pipeline/build_vocab.py data/vocab/es --lang es [--enrich]` (`--enrich` fills the other roots from Spanish Wiktionary; etymologies Wiktionary marks unknown/uncertain are skipped, zorro "perhaps from Middle French sor"; newer entries that only carry the `etymon` template are missed: 1720 of 2632 words have a root, 135 hubs) → `data/graph_es.json` (`params.lang`). The pipeline's language-specific bits (articles, stems, gender endings, Wiktionary extract, frequency list, sentence pairs, etymology codes) live in `pipeline/languages.py` (`L.use(code)`; Italian by default). **German** (`data/vocab/de/`, `--lang de`, 2606 words; translation lines in `data/vocab/de/translations/`): every noun gets its plural from Wiktionary (`Lang.all_plurals`; Spanish only where the Italian had one); compounds are families (`Lang.compounds`: a word inside another of related meaning, Handschuh – Hand, linked to its closest-meaning part; Handy – Hand is not); gender endings `""`/`e` → `in` (Lehrer/Lehrerin; `ending_pair` slices `a[: len(a) - len(m)]` so an empty ending works); etymology skips Middle/Old High German and Proto-West Germanic, takes a prefixed word's base (`affix_base`: an- + bieten → bieten), never a particle's root (`Lang.particle_roots`: *ana, *upp, *ta …, which tied anbieten to anstoßen), and only from a Wiktionary entry of the word's own part of speech (sein "his" isn't sein "to be"): 622 roots, 71 hubs. **English cousins** come from Wiktionary's cognates (`english_cognate`: looks like the word), then in the build only everyday ones (rank ≤ 20 000 in `en_50k`), related to the meaning (Numberbatch) and not the answer itself (trinken/drink gives it away): 100, pflücken → pluck, mächtig → mighty. The same word may be listed twice as different parts of speech (`vocab.validate`: sein to be / his, da there / since); an adjective and its identical adverb are one word with both meanings (langsam: slow / slowly). Conjugations: `conjugate.german` (Präsens, Perfekt, Präteritum and Futur I as Wiktionary gives them, separable verbs as said, "lege zurück", "habe angerufen"; sein when both auxiliaries are listed, aufstehen; reflexives (`sich freuen`) from the base verb, pronoun after the first word; Konjunktiv II: the own form for sein/haben/werden/wissen/modals, else the würde-form, plus a strong verb's own form as an alternative, "würde gehen / ginge", the shortest where two). Spanish conjugations: `conjugate.spanish` (present, perfecto = haber + participle, indefinido, imperfecto, futuro, condicional, present subjunctive; voseo skipped; reflexives from the base verb with me/te/se/nos/os/se).

## Verifying changes (how past sessions did it)

Typecheck + lint + tests, then a real browser run: `npm run build`, `npx vite preview --port 4173 --strictPort` (in the background), and a Playwright script in the session scratchpad using the cached Chromium at `~/.cache/ms-playwright/chromium_headless_shell-*/…/chrome-headless-shell` (scratch venv with `pip install playwright pillow numpy scipy`). Read answers from `data/graph_oic.json` to play. Pitfalls:

- A fresh DB shows the start picker: click a category button (or "Anywhere") first.
- The main graph is `?graph=oic` (the vocabulary). A never-seen word's step 1 starts typed (fast track); the button "Choose instead" switches to multiple choice (buttons `1 <meaning>`) for good. Reviews into Italian of words with an example are fill-the-gap (`.border-b-2` gap; the gloss is in `[data-gloss]`, the English sentence in `[data-example-en]`); the prompt word is `[data-prompt]`.
- Time travel lives in the menu (`getByTitle('Menu')`, then `+15 min`). An idle card offers "Next word" (Enter), which walks the game without map clicks.
- Click `header h1` before keyboard input, not `header` (it contains buttons that swallow Enter).
- The view refits as the map grows until you pan or zoom; press `f` to refit.
- Locate nodes by their colour in screenshots.
- Words listed twice (German sein "to be" / "his") confuse a helper that looks answers up by word; the card shows the part of speech.
- The verb drill only shows on a learned verb's word card: walk the map with random arrow keys until "Conjugate" appears.
- The game saves to IndexedDB: a script can't carry a game over by copying localStorage; play everything in one browser session.
- Phones: a second pass in a Playwright context with `viewport 412×915, is_mobile, has_touch` (tap, not click); shrink the viewport to ~520 px high to see the card with the keyboard up; check `document.documentElement.scrollWidth` equals the width (no sideways scroll).
- Stop the server with `fuser -k 4173/tcp`. `pkill -f` can kill your own shell.

## Architecture

```
data/vocab/<lang>/*.yaml ─ build_vocab.py ─► data/graph_oic.json (it), graph_<lang>.json ─┐
data/words*.csv ── pipeline/build_graph.py ─► data/graph*.json ─────┴► app (import.meta.glob in src/graphs.ts)
                                                                        ├─ ?graph=<name> picks a graph; each has its own DB
                                                                        └─ SQLite holds progress only
```

- `graph.json` owns words, edges, regions, roots and conjugations; SQLite owns progress. `syncGraph` (repo.ts) runs on start: it adds new words and cards and repairs frontier states. Node ids are slugs of the Italian word, so regenerating a graph keeps progress (renaming a word loses it).
- `src/useSprawl.ts`: the state hook. Opens the DB, loads `AppData`, performs all mutations (`review`, `reviewTense`, plant, hints, time travel, reset), moves the horizon (`horizon(states, game, levels, t, memory?)`) and runs the siege (`advanceSiege`) when app time moves. `levelUpOf`: a new overall level, else the first topic that rose (`LevelUp.topic`: the banner says "Family: A1.3 open").
- `src/App.tsx`: UI orchestration (sessions, cooldowns, notices, selection, which side card shows). Big file; read it before changing flows.
- `src/progress.ts`: `computeProgress` (→ `Levels`: overall + per topic), the single source of truth for what may be revealed (`levelAllows`).
- `src/config.ts`: all tunables (`TOPIC_SHARE`, `OVERALL_SHARE`, cooldown, verb points per level, `SUPPLY`, claim gaps/expiry, raids).
- `src/supplyState.ts`: from `AppData` to the supply core: `siegeWorld(data, t)` (`output`: `wordOutput` of the word's strength level and its verb tenses as of `t`; `home`: the capital; break times: a miss or the weaker direction's recall at `SUPPLY.breakRecall`; hold times: memory stability, at least a day), `supplyNow` (flow, broken, cut; `input.sources` = what each word sends out now), `outputOf`/`isStronghold` (sends out 1, the capital aside), `seep` (fog from sources), `hangingOn` (what a word carries), `freshOutput`, `flowToward` (a word's top suppliers, and while it's short of supply the gain from winning each "?" within two links).

Untouched frontier words never appear automatically. `closest` picks what "Next word" opens: an open claim step (or a broken word / win-back), else the nearest "?" (link distance + penalty 2). `nearby` keeps it local: App only serves cards of the selected word (`selectedId`, also set by answering) and words linked to it; otherwise it stays put and says how many are due elsewhere (attention kind `due`, N / jump bar). |
| `roots` | root hubs as hyperdrives: `rootCharge` (each family word counts the supply at it as a share of `SUPPLY.min`, up to 1), `rootOpenings` (charge ≥ `rootNeed` = `ROOTS.open` 3, or the whole family if smaller). `useSprawl.horizon` opens them (only hubs with a conquered word, i.e. visible) and turns all their hidden words into "?" at any level; meta `unlocked_roots`. No quiz. |
| `health`, `fade` | health = a word's recall, its weaker direction (`nodeHealth`); `forgetAt` = when that falls to a line. Names erode letter by letter from 90% (due) to 80% (broken, `NO_NAME`), then show "?"; `hintedName` keeps ~⅓ of the letters while an en→it card is due (`RECALL_NAME`). Bands: solid ≥ 90%, faded, dashed, cracked ≤ 80%. |
| `strength` | FSRS stability → level 0–5 ("memory strength", shown as blue dots with "lasts ~N", `MemoryDots` in NodeDetails; ★ are only for verb tenses); `nextPractice` (no cramming: practice only when due, `dueAt`). A cut-off word holds out as long as its stability (at least a day). `memoryOutlook` (NodeDetails/WordInfo `MemoryPanel`): due (90%), breaks (80%), since (last review), and the next level: how many right answers, each when due, and when (simulated with FSRS Good ratings). The level also sets what a word sends out (`SUPPLY.output`): a fresh conquest is level 2 (stability ~3.2 d), its first review (day 3) makes 3, ~day 14 4, ~day 49 5. |
| `game` | `GameNode` per word (meta `game`): `claim`, `fallen`, `missedAt` (a miss or undefended raid broke it until a right answer), `cutSince` (siege clock); `Game.simAt` = siege run up to. `neighbourWeights`, `without`. Older saves' influence fields are dropped on load (`parseGame`). |
| `supply` | **the supply network (organic, additive).** Every held, unbroken word is a source: `wordOutput` = `SUPPLY.output[strength level]` (0.05/0.1/0.25/0.4/0.65/1) + `perTense` 0.1 per learned verb tense, capped at 1; the capital (`home`) sends 1 once conquered (before that it sends nothing, like any word you don't hold: it used to, and a neighbour of an unconquered capital showed a puzzling +30%; `sourcesAt`). `supplyFlow`: per source a widest-path search (`spread`) through carriers (held, unbroken); each link passes on its strength (capped `SUPPLY.maxLink` 0.9); non-carriers receive but pass nothing on, or their `fog` share (the horizon); shares under `SHARE_MIN` (0.01) are dropped. **A word's supply is the sum of the shares of all its other words** (its own never counts, not even echoing back; the capital adds its own 1). A held word with ≥ `SUPPLY.min` (0.5) is supplied, else cut off. Runs on flat typed arrays (`linkIndex`, `NumHeap`) and keeps each source's shares (`Supply.shares`), so `hanging` (held words cut off if one broke: chokepoints) only recounts words that could drop below `min`, with only the sources whose supply passed *through* the word (`through`), and `advanceSiege` `reroute`s the same way at each break or fall (tests check both against full recounts). ~20 ms for 500 held words; one `hanging` ~3 ms. `contributions` (a word's suppliers: share and path), `gainIfWon` (what winning a word would add to another's supply: only the sources reaching the candidate are searched again; tested against a full recount), `coverage` (what a capital would reach if everything were held), `sourcesAt`, `advanceSiege` (event-ordered: breaks and falls in time order, so a week away plays out correctly; outputs change only at answers; cut-off words fall after their hold time), `horizonChanges` (hidden words next to anchors, or reached by summed fog supply ≥ `SUPPLY.reveal` 0.3, become "?"; lone untried "?" go back), `ghostWords` (fog supply ≥ `SUPPLY.sight` 0.12, below `reveal`: ghosts; less stays unseen). | `tiers` | **levels** (`computeLevels`, `Levels`): every **topic** (category) climbs its own ladder of CEFR sub-levels (A1.1 … C1, tiers 1–10): its level k+1 opens at `TOPIC_SHARE` (0.6) of its own words of levels 1..k conquered (a level with none of its words passes at once), and only its words up to its level can be revealed (`levelAllows`). ## Game rules (current)

- **Start:** a new game asks where to begin (a category, or anywhere), then (for a category) your **capital**: the first word, which always sends out full supply, chosen from the category's start candidates by how far its supply would reach (or by chance). Every topic has words up to A2, which the one-band rule opens from the start. Before its first conquest the capital shows only its neighbours (it stays a horizon anchor, `useSprawl.horizon`) and sends no supply yet ("your capital: sends 100% once it's yours").
- **Levels and runs:** each topic climbs its own level; the overall level (words held anywhere + verb points) lets topics run at most one band ahead (see `tiers`). Several runs per word list (menu → Runs).
- **Flow:** an idle card (nothing due here, or a word waiting/locked) offers "Next word" (Enter): an open claim step first, else the nearest "?".
- **Clicking empty map** lets go (App `clearSelection`, GraphView `onBackgroundClick`): no word selected (white rings and keyboard cursor gone; arrows resume from where the cursor was), open cards and panels closed (review card, word info, wait card, verb drill, plant picker, 🏆 and level panels). The panel rests (`deselected`: no due card jumps in, "N due elsewhere") until a word is picked; "Next word" still starts from the last word. In the whole-network view it clears the inspected word.

- **Claiming:** click a "?" (or move to it with the arrow keys) to get step 1, Italian → English. A correct answer makes it **claimed** (fragile). Step 2 (English → Italian) opens 1 min later and step 3 (either way) 5 min after that. A never-seen word's step 1 always starts typed; typed right at first sight = you knew it: step 2 opens 30 s later and conquers it (fast track). "☰ Choose instead" shows four meanings (keys 1–4) one way: no fast track and no going back to typing.
- **Examples:** reviews of conquered words into Italian are fill-the-gap when the word has an example (the gap's form or the full word both count); every revealed answer shows the example with 🔊.
- **Answers:** English alternatives separated by " / " are all accepted, and a note in brackets need not be typed ("clubs (card suit)" → "clubs"). A noun's plural (`pl`, one node for both forms) typed for the English prompt counts as almost ("Singular: …"); reveals and word cards show "pl. …".
- **Supply (core/supply.ts):** your words count only while the words around them hold them up. Every word you hold sends out supply by how well you know it (memory strength: 25% fresh, 40% after its first review, 65% after two weeks, 100% after ~7 weeks, a **stronghold** with a tower and a banner; verbs +10% per tense); the capital always sends 100%. Each word's supply flows along links through held, unbroken words, each link passing on its strength; a word gets the shares of all its other words added up and needs 50% (often well over 100% inside a territory). So new words need well-known words nearby, and a few linked words far from home hold each other once reviewed (an outpost). A held word **breaks** when you miss it (or an undefended raid hits it) or when its weaker direction's recall falls to 80% (its name has faded completely); a broken word passes nothing on, so what hangs on it is **cut off**: grey, no score, and it holds out as long as its memory lasts (at least a day) before falling back to "?" (win it back within 3 days with one right answer). One right answer mends a broken word and everything behind it lights up. Remedies: mend the gap, win or strengthen the words around it, plant a link around it. The details panel says how many words hang on a word; due reviews near you come chokepoints first. You can conquer outside your supply (faint "?"), but such words are cut off from the start.
- **Fast-forward** (App, `FAST_FORWARD` in config, `useSprawl.skipAhead`): when nothing can be answered (no card on screen or queued, no attention but "new" outside cooldown, no pop quiz or focus running) and something opens within 15 min app time (a learning step, a lock, a card or tense coming due), app time runs up to 120× (a jump every 500 ms; at most ~8 s of waiting) until it does, with a "Fast-forward ×N" bar at the bottom left of the map; with no "?" to go to either, the idle card says "Next word ready in m:ss". It starts 2 s after an answer (`settleMs`), but runs slower (`fastRate` in core/clock) where it would bring back the word you answered less than 30 s (real) ago (`sameWordMs`, the fast track's anti-copy gap). It used to wait 30 s after any answer, which early on (two or three words, all waiting) was half a minute of nothing. Never towards reviews further off (cramming); new words don't count as something to do (else it would never run). The offset is saved once it settles, and the siege waits for that too (each run saves the whole DB). The author asked for it (Sep 2026).
- **Expeditions, raids, streak:** see `expedition`, `raid`, `streak` above. Raids strike after a right answer (15%, ≥ 20 min apart): up to 3 supplied words (chokepoints more likely, the capital never), 3 min to answer each right (raided words can always be practised, always en→it: the raid bar names them in English and the queue holds back their it→en card); undefended ones break; repelled = +3 coins. Expedition: 5 words of one category in 10 min, +10 coins. Clicks and the automatic queue only offer the open step. A never-seen word offers "Show me", which is not penalised.
- **Visual feedback:** territory grows with every claim step (and more on conquest and with verb levels). Claim steps, conquests and verb levels flash a burst on the map. A verb level also shows a gold banner, and the verb gets bigger with a gold outline and "★ tense" under its name. Link width follows the weight's rank in the graph (raw weights bunch up in 0.25–0.6). Gold pulses run along supply lines and a pale light lies where supply is strong (see GraphView). Conquered words show their root (pink) when zoomed in; etymology is in the status panel except while the word is being asked. The legend is in the guide.
- **Horizon and ghosts:** every hidden word next to one of your words (or a working capital) is a "?"; strong supply also seeps further (fog): words two links out, rarely three, open too (from words you hold: the better you know them, the further they see). A little seeping supply (4–8%, from any source) makes a ghost: faint, not conquerable yet (clicking one says so); none leaves a word unseen. Visibility, glow and supply are one scale. Untried "?" left without an anchor go back to hidden. A claimed word waiting for its next step has a white countdown ring.
- **Names are earned:** a word's Italian name appears on the map only once it is conquered. It is also hidden (map, tooltip, status panel) while it is the answer being asked. While an en→it card of it is due (or it is raided) the name shows only about a third of its letters (`hintedName`, `RECALL_NAME` in `core/fade`), so the map doesn't give the answer away before the card opens. Claimed words show "?" with a 3-segment ring.
- **Attention:** broken words (rose), raided words (orange), ready claim steps (green), due words (violet) and newly revealed words (light blue) ripple. Off-screen ones get arrows at the view edge, and the top-right jump bar or `N` cycles through them. A due card for an off-screen word pans the camera to it.
- **Score, achievements, coins:** the header's score and sparks (coins) open the progress panel (score per category (supplied words only), achievements). Coins: +`COINS_PER_CONQUEST` per real conquest (not a win-back) plus achievement rewards. **Planting** (from `PLANT_COST` coins, more for later levels): on a conquered word's details, "🌱 Plant a word" opens `PlantPicker` (options by English meaning). The chosen hidden word becomes "?" next to it, joined by a player link (`via: 'user'`, meta `user_edges`, merged into `data.edges`, so it carries supply and counts for the horizon and score: a planted detour protects a chokepoint). Drawn as a green dash-dot link.
- **Hints:** for `HINT_COST` coins a visible word shows its English cousin (`cognate`) as a small amber node tied to it (meta `hints`, not an edge: no score, no supply). Words without a curated `cousin` get one from the pipeline (`pick_cognate`: the root's English descendant that looks like the word and relates to its meaning; precision over coverage).
- **Lost is not forgotten (`core/fallen.ts`):** a conquered or claimed word that falls back to "?" (siege, expired claim, a miss on a claim) keeps `fallen {was, steps, at}` on its game node. For `RECLAIM_MS` (3 days app time) one right answer restores it as it was (conquered, or the claim with its steps done as of now); teal ↺ ring on the map, attention kind `reclaim`, "Winning back" banner. After that it's fully lost.
- **Misses:** a real miss locks the word for 60 s (app time); a held word breaks (`missedAt`, see Supply) and the notice says how many words it cut off; a claimed word falls back to "?". Unfinished claims expire after 24 h.
- **Conquered words:** clicking or jumping to one practises only its due cards (or its weakest card when it's fading but not due), never the not-due other direction. Conquest graduates both FSRS cards (the unanswered direction gets a Good too, unlogged via `saveCard`), so a new conquest isn't asked again at once. They can be practised only when due, broken or raided (the status panel shows "due in"). Clicking a solid one opens `WordInfo`.
- **Tiers** (levels) come from word frequency or a `tier`/`level` column (CEFR names in `graph.params.tier_names`). Verb points gate the overall level (see `tiers`); the header level chip opens the level panel with topics and verbs.
- **Roots** shared by 2+ words are hexagon hubs, shown once one of their words is conquered. A sealed hub charges (pink ring) as its words come inside your supply and opens by itself at 3 (see `roots`): its English cousins show and all its words become "?" anywhere on the map (a hyperdrive). Clicking a hub shows a wait card with its charge or meaning.
- **Map:** the layout is organic (force simulation). Invisible same-category springs gather discovered words, and territories are contours of the words' summed fields (fused blobs) whose size grows with word strength.

## Pipeline notes

- **Meaning score:** ConceptNet Numberbatch on the English gloss (hyphens become underscores: `mother_in_law`, `great_grandmother` are phrase vectors), which captures association (dog→bark). Sentence-embedding models only capture likeness and did worse in a labelled benchmark; `--model BAAI/bge-m3` still works.
- **Categories:** the vocabulary's 44 files (`vocab.CATEGORIES`, map order = related categories adjacent), every word in exactly one. CSV lists: their themes; untagged words join a theme only if they clearly fit (`THEME_FIT` 0.45, `THEME_MARGIN` 0.1), else stay **independent** (`region: null`).
- **Vocabulary links (`build_vocab.py`):** (1) per category a tier-respecting spanning tree plus each word's top 2 partners there from 0.35 (score 0.7 meaning + 0.5 family + 0.15 same category); (2) families: a shared root always, a shared stem only when the meanings relate (≥ 0.25: la cucina/cucinare yes, la casa/il caso no), each member linked to its closest more common relative; (3) at most one direct bridge per word to another category, same part of speech, meaning ≥ `BRIDGE_MIN` 0.55, never when the two English glosses share a word (English homographs: il diritto "right"/la destra "right", il disegno "drawing"/trarre "to draw") or rest on an ambiguous English word (`AMBIGUOUS`: will, can, show, close…); (4) categories joined into one map by their best low-tier bridges; (5) **male/female pairs** (`counterparts`: any meaning of the gloss swaps into one of the other's, mother↔father, "child / little boy"↔"little girl" via `GENDER_PAIRS`, or Italian -o/-a, -e/-a, -tore/-trice, -e/-essa with the same main meaning, il cugino/la cugina "cousin"; both kinds of evidence together win) are linked and share their links: a link to another pair member is mirrored onto its counterpart; a link to an unpaired word is copied unless it is a family (root/stem) link (la sorella – la suora stays hers) or that word's English is gendered (la figlia – la signorina "young lady"); (6) YAML `links`/`unlink` win. `via`: tree/theme/family/bridge/manual. Tiers: each word's CEFR `level` (or its frequency: `vocab.word_rank` = most common inflected form in subtitles, `LEVEL_BY_RANK`) split into 10 even sub-levels A1.1…
- **CSV-graph links (`build_graph.py`):** score = 0.6 semantic + 0.25 same stem + 0.25 shared root + 0.15 same theme. Edges are a tier-respecting maximum spanning tree plus top-3 bonus links scoring ≥ 0.25. Lists with themes first assign untagged words to a theme, then add in-category links (`via: 'theme'`): a tier-respecting spanning tree per category plus each word's top 2 partners there from 0.3, so no category falls apart (OIC went from 266 pieces in 31 categories to 31). In the app, links between categories are twice as long and 0.3× as strong in the force layout. Lists with themes use them as regions, else Louvain communities (`layout.py`).
- **English cousins (hints):** a generated cousin must look like the word *and* evoke its meaning (Numberbatch similarity to the gloss ≥ `COGNATE_MIN_RELATED` 0.18, and not be the gloss itself): pancia → panzer, testa → test, letto → lecture are out. Root hubs keep only English words related to the root's meaning or one of its words (`HUB_MIN_RELATED`).
- **Etymology:** hand-curated columns in `words.csv` (root, root_lang, root_meaning, cognate, cognate_note). Generated lists use Wiktionary (kaikki.org) with deliberately conservative root-family rules: homographs produced wrong families, and a wrong etymology is worse than none.
- **Conjugations:** `conjugate.py` reads Wiktionary forms. Stress accents are normalised, passato prossimo is built from auxiliary + participle, reflexives are handled, and `-sene` verbs are skipped.
- **Caches** (~1.3 GB, auto-downloaded) live in `~/.cache/sprawl/`: Numberbatch, kaikki Italian/Latin/English, frequency lists, pickled indexes. Delete an `*.pkl` to rebuild its index.
- `data/vocab/`, `data/sources/` and `graph_oic.json` are git-ignored (partly derived from the onlineitalianclub.com scrape and a third-party frequency table: personal study only). Whether to track the vocabulary in git is the author's call.

## Conventions

- Rust stays a thin shell; logic lives in TS.
- Commit after each feature with a descriptive message (co-author trailer). The remote `origin` is the author's **personal** GitHub (`mcaldera/lexinet`), never the ProxygenTx org. Ask before pushing.
- Match the surrounding style; comments explain why, not what. Prettier (single quotes, width 100): run `npx prettier --write src` after edits. It reflows lines, so re-read before making exact-string edits.
- Keep CLAUDE.md current when rules or architecture change.
